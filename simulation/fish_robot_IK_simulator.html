Forward kinematics (Eq. 2a–d)
θ₃ = arcsin(C / √(A²+B²)) − arctan(B/A)
A = RaRb(cosθ₁−cosθ₂) + Rb(L₁+L₂)
B = RaRb(sinθ₂−sinθ₁)
C = Ra²·sin(θ₁−θ₂) − Ra(sinθ₁·L₂ + sinθ₂·L₁)
IK — Symmetric mode
θ₁ = θ₂ = −arcsin( Rb/Ra · sinθ₃* )
Valid when |Rb·sinθ₃*| ≤ Ra
IK — Asymmetric mode (θ₂ fixed)
P·sinθ₁ + Q·cosθ₁ = S
θ₁ = arctan(Q/P) ± arccos(S / √(P²+Q²))
Two branches → pick one within motor range
Velocity IK — asymmetric mode (Eq. 3 inverted)
θ̇₁ = θ̇₃* · Rb·cos(θ₃−θ_rod) / [ Ra·cos(θ₁−θ_rod)·(1 + d₁/(d₁+d₂)) ]
Note: state-dependent gain — changes as mechanism moves
Tail angle (Eq. 7)
θa = Rb·θ₃ / d where d = wire offset from spine centreline
